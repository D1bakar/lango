How it works

Learn → Produce → Keep.

01 — Learn

Flip 5 cards. Say each out loud. Roman + example included for Japanese, Korean, Chinese.

02 — Produce

Type the translation, hear it with TTS, then 5-question check with instant feedback.

03 — Keep

+10 XP per correct. Weak words (mastery < 4) return in Review until they stick.

Questions, answered.

Do I need an account?

No. Progress is localStorage key lango.v2. Export it in Settings if you switch devices.

Does it work offline?

Yes after first load — service worker caches shell + 22 course files.

How is Japanese taught?

Kana/kanji + romaji + TTS voice ja-JP. Typing accepts romaji-tolerant matches.
