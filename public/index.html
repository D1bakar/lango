Questions, answered.

Do I need an account or internet?

No account. Internet once to load the page — after that the lesson runs from cached files and localStorage.

Where is my progress stored?

Only in this browser (localStorage key lango.v1). Clear site data and it resets. Nothing is uploaded.

How long is a lesson?

About 5 minutes: 5 flashcards at your pace, then 5 multiple-choice questions with instant feedback.

Which course should I start with?

If you speak English, start Spanish. If you speak Spanish, start English. Both cover the same 10 survival words.
